# CityDrive Personal Account

## О проекте

**CityDrive Personal Account** - это веб-приложение для управления корпоративным транспортом и поездками сотрудников. Система позволяет компаниям эффективно управлять служебными поездками, отслеживать расходы, управлять сотрудниками и отделами.

### Технологический стек

- **Frontend**: React 19 + TypeScript
- **State Management**: Redux Toolkit + RTK Query
- **Build Tool**: Webpack 5
- **Styling**: SCSS
- **Testing**: Jest + Testing Library + Cypress
- **Code Quality**: ESLint + Prettier + Stylelint
- **Documentation**: Storybook
- **Visual Testing**: Lost Pixel

### Архитектура

Проект построен по методологии **Feature-Sliced Design (FSD)**, которая обеспечивает четкое разделение кода по слоям ответственности.

## Сущности (Entities)

### Employee
**Модель сотрудника компании**
- Личные данные и контактная информация
- Рабочие параметры (график, лимиты)
- Финансовая информация (баланс, расходы)
- Настройки уведомлений

### Department  
**Модель отдела компании**
- Информация об отделе
- Финансовые лимиты и расходы
- Привязанные сотрудники

### Route
**Модель маршрута поездки**
- Прямые маршруты (точка А → точка Б)
- Маршруты с промежуточными остановками
- Информация о времени и стоимости

### Invoice
**Модель счета/финансовой операции**
- Детали финансовых операций
- Статусы оплаты

### Notification
**Модель уведомлений**
- Системные уведомления
- Уведомления для пользователей

## Виджеты (Widgets)

### Navbar
**Навигационная панель**
- Основная навигация по приложению
- Информация о пользователе
- Индикаторы уведомлений

### EmployeeInfo
**Информационная карточка сотрудника**
- Отображение ключевой информации о сотруднике

### RouteMap

### Stat
**Виджеты статистики**
- Различные типы статистических виджетов
- Графики и диаграммы

### PageLoader
**Индикатор загрузки**
- Состояния загрузки для страниц и компонентов

## Структура проекта

```
src/
├── app/           # Слой приложения (роутинг, провайдеры, глобальные стили)
├── entities/      # Слой сущностей (бизнес-модели)
├── features/      # Слой фич (бизнес-функционал)
├── widgets/       # Слой виджетов (составные UI компоненты)
├── pages/         # Слой страниц (композиции виджетов и фич)
└── shared/        # Слой общего кода (ui, lib, utils)
```

### Принципы FSD

1. **Снизу-вверх**: Каждый слой может зависеть только от нижележащих
2. **Четкие границы**: Явное разделение ответственности между слоями
3. **Public API**: Каждый модуль имеет четкий публичный интерфейс
4. **Независимость**: Модули одного слоя не зависят друг от друга

## Вклад в проект

### Добавление новой фичи

1. Создать папку в `src/features/`
2. Реализовать структуру: `api/`, `model/`, `ui/`
3. Создать `index.ts` с public API
4. Добавить документацию `README.md`
5. Написать тесты и Storybook истории
