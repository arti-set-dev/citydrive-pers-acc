# Navbar Widget

## Описание

Виджет `Navbar` представляет собой навигационную панель приложения CityDrive. Обеспечивает основную навигацию между разделами личного кабинета и доступ к ключевым функциям системы.

## Как использовать

```typescript
import { Navbar } from '@/widgets/Navbar';

// В компоненте Layout
<Navbar />
```

## Public API

### Компоненты
- `Navbar` - Основной компонент навигационной панели

## Особенности

- **Адаптивный дизайн**: Поддерживает отображение на мобильных и десктопных устройствах
- **Интеграция с роутером**: Автоматически подсвечивает активный раздел
- **Контекстная навигация**: Отображает разные пункты меню в зависимости от роли пользователя
- **Уведомления**: Показывает индикаторы новых уведомлений и сообщений
- **Профиль пользователя**: Быстрый доступ к профилю и настройкам

## Структура навигации

- **Главная**: Общая информация и статистика
- **Сотрудники**: Управление сотрудниками компании
- **Отделы**: Управление отделами
- **Поездки**: История и управление поездками
- **Счета**: Финансовая информация
- **Промокоды**: Управление промокодами
- **Настройки**: Настройки профиля и компании

## Интеграция

Виджет интегрирован с:
- Системой аутентификации для отображения данных пользователя
- Системой уведомлений для индикаторов
- Роутером для навигации
- Системой прав доступа для фильтрации пунктов меню
