# Pages Layer

## Описание

Слой `pages` содержит композиции виджетов и фич для создания полных страниц приложения. Каждая страница представляет собой полный экран с определенным функционалом.

## Структура

Каждая страница следует единой структуре:
```
PageName/
├── index.ts          # Public API страницы
├── PageName.tsx      # Основной компонент страницы
└── PageName.module.scss # Стили страницы
```

## Принципы построения страниц

### Композиция
Каждая страница является композицией:
- **Виджеты** (widgets) - крупные UI компоненты
- **Фичи** (features) - бизнес-функционал
- **Сущности** (entities) - данные и модели

### Структура типичной страницы
```typescript
export const EmployeesPage = () => {
  return (
    <Page>
      <PageHeader title="Сотрудники" />
      <EmployeesFilter />
      <EmployeeList />
      <AddEmployeeButton />
    </Page>
  );
};
```

### Ленивая загрузка
Страницы поддерживают ленивую загрузку для оптимизации:
```typescript
const EmployeesPage = lazy(() => import('./EmployeesPage'));
```

## Особенности

- **Адаптивность**: Все страницы адаптированы под мобильные устройства
- **SEO**: Поддержка мета-тегов и заголовков
- **Защита**: Некоторые страницы требуют аутентификации
- **Оптимизация**: Ленивая загрузка и код-сплиттинг
- **Навигация**: Интеграция с breadcrumbs и навигацией

## Public API

Каждая страница экспортирует:
- Основной компонент страницы
- Типы данных (если есть)
- Хуки (если есть специфичные для страницы)

## Пример использования

```typescript
// В роутере
{
  path: '/employees',
  element: <EmployeesPage />,
  meta: {
    title: 'Сотрудники',
    requiresAuth: true
  }
}
```
