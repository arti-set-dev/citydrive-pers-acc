# App Layer

## Описание

Слой `app` является верхним уровнем приложения по методологии FSD. Содержит глобальные настройки, провайдеры, роутинг и общие компоненты, которые используются на уровне всего приложения.

## Структура

### providers/
Глобальные провайдеры приложения:
- **Redux Provider**: Оборачивает приложение в Redux store
- **Router Provider**: Настройка роутинга
- **Theme Provider**: Провайдер тем оформления
- **Error Boundary**: Обработка ошибок на уровне приложения

### router/
Конфигурация роутинга:
- **Routes**: Определение всех маршрутов приложения
- **Navigation**: Настройка навигации
- **Guards**: Защита маршрутов (аутентификация, роли)

### store/
Глобальное состояние Redux:
- **Root Reducer**: Корневой редюсер
- **Middleware**: Настройка middleware (RTK Query, logger)
- **DevTools**: Настройка Redux DevTools

### styles/
Глобальные стили:
- **Variables**: SCSS переменные
- **Mixins**: Переиспользуемые миксины
- **Global**: Глобальные стили приложения
- **Themes**: Темы оформления (светлая/темная)

### types/
Глобальные типы приложения:
- **AppState**: Типы глобального состояния
- **Router**: Типы для роутинга

## Основные компоненты

### App.tsx
Корневой компонент приложения:
- Оборачивает приложение в провайдеры
- Настраивает глобальные контексты
- Обрабатывает глобальные ошибки

### Layout.tsx
Основной макет приложения:
- Навигационная панель
- Боковая панель
- Основная контентная область
- Футер

## Особенности

- **Инициализация**: Глобальная инициализация приложения
- **Провайдеры**: Централизованное управление контекстами
- **Роутинг**: Единая система навигации
- **Стили**: Глобальные переменные и темы
- **Ошибки**: Глобальная обработка ошибок

## Принципы

1. **Глобальность**: Содержит только то, что используется на уровне всего приложения
2. **Инициализация**: Ответственность за запуск и настройку приложения
3. **Интеграция**: Связывает все слои в единое приложение
4. **Конфигурация**: Глобальные настройки и конфигурации

## Пример использования

```typescript
// App.tsx
export const App = () => {
  return (
    <BrowserRouter>
      <Provider store={store}>
        <ThemeProvider theme={theme}>
          <ErrorBoundary>
            <Layout>
              <AppRouter />
            </Layout>
          </ErrorBoundary>
        </ThemeProvider>
      </Provider>
    </BrowserRouter>
  );
};
```
