# Employees Filter Feature

## Описание

Фича `employees-filter` предоставляет функционал для фильтрации и поиска сотрудников в системе CityDrive. Позволяет быстро находить нужных сотрудников по различным критериям.

## Как использовать

```typescript
import { EmployeesFilter } from '@/features/employees-filter';
```

## Public API

### Компоненты
- `EmployeesFilter` - Компонент фильтрации сотрудников

## Особенности

- **Множественные критерии**: Фильтрация по имени, отделу, роли, статусу
- **Реальное время**: Мгновенное обновление результатов при изменении фильтров
- **Сохранение состояния**: Фильтры сохраняются в URL и при перезагрузке страницы
- **Сброс**: Быстрый сброс всех фильтров
- **Дебаунс**: Оптимизация поисковых запросов для снижения нагрузки

## Критерии фильтрации

- **По имени**: Поиск по имени или фамилии сотрудника
- **По отделу**: Фильтрация по принадлежности к отделу
- **По роли**: Фильтрация по роли (admin, user)
- **По статусу**: Фильтрация по статусу (active, inactive)
- **По лимиту**: Фильтрация по размеру финансового лимита
- **По расходам**: Фильтрация по потраченной сумме

## Интеграция

- Работает с сущностью `Employee` для получения данных
- Использует глобальное состояние для хранения фильтров
- Интегрирована с системой роутинга для сохранения состояния
- Поддерживает мобильную адаптацию

## Пример использования

```typescript
// В компоненте списка сотрудников
<EmployeesFilter 
  onFilterChange={handleFilterChange}
  initialFilters={urlFilters}
  availableDepartments={departments}
/>
```
