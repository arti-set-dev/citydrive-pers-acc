# Add New Employee Feature

## Описание

Фича `add-new-employee` предоставляет функционал для добавления новых сотрудников в систему CityDrive. Включает форму для ввода данных сотрудника с валидацией и сохранением.

## Как использовать

```typescript
import { 
  AddNewEmployeeForm,
  AddNewEmployeeSchema
} from '@/features/add-new-employee';
```

## Типы данных

### AddNewEmployeeSchema

Схема данных формы добавления сотрудника:

```typescript
interface AddNewEmployeeSchema {
  // Поля формы для создания нового сотрудника
  // Включает основные данные: имя, email, телефон, роль и т.д.
}
```

## Public API

### Компоненты
- `AddNewEmployeeForm` - Форма добавления нового сотрудника

## Особенности

- **Валидация**: Клиентская и серверная валидация полей
- **Автосохранение**: Возможность сохранения черновика
- **Интеграция**: Автоматическое добавление в систему после создания
- **Уведомления**: Уведомления об успешном добавлении или ошибках
- **Асинхронность**: Поддержка индикации загрузки при сохранении

## Поток использования

1. Пользователь открывает форму добавления сотрудника
2. Заполняет обязательные поля (имя, email, роль)
3. Система валидирует введенные данные
4. При успешной валидации данные отправляются на сервер
5. Сотрудник добавляется в систему и появляется в общем списке

## Интеграция

- Работает с сущностью `Employee` для создания новых записей
- Использует общие компоненты из `shared/ui`
- Интегрирована с системой уведомлений
- Поддерживает навигацию после успешного создания
