# Shared Layer

## Описание

Слой `shared` содержит переиспользуемый код, который может использоваться во всех частях приложения. Это фундаментальные элементы, которые не зависят от бизнес-логики и могут быть использованы в любых сущностях, фичах, виджетах или страницах.

## Структура

### api/
Общие конфигурации и утилиты для работы с API:
- Базовые настройки RTK Query
- Общие типы ответов API
- Утилиты для обработки ошибок

### assets/
Статические ресурсы:
- Изображения
- Иконки
- Шрифты
- Стили

### hooks/
Переиспользуемые React хуки:
- Пользовательские хуки для работы с состоянием
- Хуки для работы с API
- Утилитарные хуки

### lib/
Библиотеки и утилиты:
- Функции для работы с датами
- Валидаторы
- Форматтеры
- Константы

### types/
Общие TypeScript типы:
- Глобальные интерфейсы
- Типы для API
- Общие модели данных

### ui/
Библиотека UI компонентов:
- Базовые компоненты (Button, Input, etc.)
- Составные компоненты
- Хуки для UI
- Темы и стили

### utils/
Общие утилитарные функции:
- Хелперы для работы с данными
- Функции форматирования
- Математические утилиты

## Особенности

- **Независимость**: Компоненты и утилиты не зависят от бизнес-логики
- **Переиспользование**: Могут использоваться в любом слое приложения
- **Типизация**: Полная TypeScript поддержка
- **Тестируемость**: Легко тестировать в изоляции
- **Документация**: Каждый компонент имеет свою документацию

## Принципы использования

1. **Только общее**: В shared должен попадать только действительно переиспользуемый код
2. **Без зависимостей**: Не должен зависеть от сущностей, фичей или виджетов
3. **Стабильность**: Изменения в shared не должны ломать другие части приложения
4. **Документация**: Все public API должны быть задокументированы

## Примеры использования

```typescript
// UI компоненты
import { Button, Input } from '@/shared/ui';

// Утилиты
import { formatDate, validateEmail } from '@/shared/lib';

// Хуки
import { useDebounce } from '@/shared/hooks';

// Типы
import { ApiResponse } from '@/shared/types';
```
